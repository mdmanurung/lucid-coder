# Corpus persona: how the human computational biologists code

Paths are relative to `cc_learnings/repos/` or `repos_new/`. `nb:cellN` is a notebook code cell. Read on 2026-10-28 from 10 repos: immgenT, sound-life, aifi, MOCHA, IHA, multiple-myeloma, dreamlet_analysis, cns-haematopoiesis, IFN, single_cell_aging.

## Evidence by question

1. **Shape.** Three templates. Allen notebook: title markdown, `warnings`+imports, cutoff cell (`max_mito = 10`), helper defs, "Identify files" by UUID, output-name dict, loop over groups, `pd.concat`, `upload_files(input_file_ids=in_files)`, `session_info.show()` (sound-life `02-reference_labeling/05-...qc_filtering.ipynb` cells 2-45). immgenT script: header, `library()`, `data_path`/`figure_path`, `source()` with the used functions in a trailing comment, load, one banner block per panel (`script/Figure3.R:42-128`). Hoffman Rmd: YAML, setup chunk `cache = TRUE`, libs, load, one chunk per model step with a `form =` object (`dreamlet_analysis/Nathan_NatImm_2021/Nathan_NatImm_2021.Rmd:14-24, 153-159`).
2. **Comments.** Banner names the panel or step; inline comments give the reason for a value at its point of use: `# A high AUC only means "GP predicts this category" when...` (`Figure4.R:137-139`); `# max_workers=30; adjust to match available cores` (MM `01-predict_doublets.py:67`); marker lists annotated per gene (aifi `03-Subclustering/07-Python_B_cells.ipynb` cell 13). Notebooks use markdown headings instead of banners. No docstrings on one-use functions; roxygen only in shared R helpers (MM `frequency-volcanos.R:14-21`).
3. **Naming.** snake_case, data-noun first then qualifier: `seurat_meta_filtered`, `L_pm_no_thymocytes_healthy`, `df_mde_gcd`. Plots are `p_3A`, `p_4c`. Functions are verb_noun: `plot_gp_swarm`, `compute_auc_matrix`, `apply_qc_filters`, `read_adata_uuid`. Files are `NN-Language_task` or `FigureN.R`; outputs carry step, group and date: `diha_pbmc_{group}_pseudobulk_deseq2_{Sys.Date()}.csv` (aifi `36-R` cell 22).
4. **Functions.** Inline until a block runs in a loop or twice; then a local function above first use, taking data and returning one value or a named list: `masked_max()` returns `list(value=, name=)` (`Figure4.R:154-160`); `process_adata()` (sound-life `10a` cell 11); `apply_qc_filters()` returns one counts row (`05` cell 9). 10-40 lines. Shared only when 2+ scripts use it: `plot_utils.R:1-3`, helper named at the `source()` line (`Figure3.R:53-56`).
5. **Repetition.** Best form: a dict or named vector drives both loop and lookup (`contrast_sets` then `.items()`, sound-life `04-file-sets/Python_assemble_deg_results.ipynb` cells 12-16; `gp_letter` loop `Figure3.R:348-370`); `map2_dfr(deseq_res, names(deseq_res), format_deseq_results, ...)` (aifi `36-R` cell 20); `names(contrasts) %>% map_df(... mutate(coef = x))` (`Kfoury_CancerCell_2021.Rmd:181-187`). Worst form coexists: eight pasted `mclapply` blocks (MOCHA `Fig3/Fig3E_DiscriminativePower.R:40-99`), per-contrast blocks pasted (aifi `36-R` cells 16-30), per-subset notebook copies (`10a`-`10g`).
6. **Checks.** Existence guards, not exceptions: `if not os.path.isdir(cache_path)` (`05` cell 6), `if os.path.isfile(out_file):` skip (`10a` cell 27). `stop()` only inside helpers with a plain sentence (`code/R/centered_mean_heatmap.R:55-57`). One script-level alignment check: `stopifnot(identical(manual_comments$GP, gp_labels))` (`script/ExtendedDataTable1_GP_summary.R:81`). `tryCatch` only as a package fallback (`plot_utils.R:49-50`). Hoffman: zero checks, zero seeds. `try/except` appears in 17 of 164 Allen notebooks, all around platform downloads (`except: pb1_fail_list.append(pb1_chunk)`, aifi `Python_assemble_PB1_flow_data.ipynb`); none around analysis. Drops are logged as data rows, not prose (`05` cell 9, 35).
7. **Division of work.** Numbered compute steps write `.rds`/`.h5ad`/parquet/CSV named for the step; figure scripts only read them (`code/pipeline/02_compute_auc.R` writes, `Figure3.R:66` reads). Judgement steps are notebooks, batch steps are scripts under SLURM (MM `02-object-building`). Notebooks never call notebooks; shared code via `source()` or `sys.path.insert` (MM `01-predict_doublets.py:37`).
8. **Plots.** Compute a tidy data frame, `p_X <- ggplot(...)`, `ggsave(file, p_X, width=, height=)` per panel (`Figure1.R:63-88`). Source data from the plotted object: `umap_df <- p1[[1]]$data; fwrite(..., "Fig1b.csv")` (IFN `IFN_Fig1.ipynb` cells 13-14); `bar_record` CSV written beside `4c.pdf` (`Figure4.R:529-530`). Python: `fig, axes = plt.subplots(figsize=(60/25.4, 18/25.4))`, loop over panels, `savefig(..., bbox_inches="tight")` (IHA `Figure3/02_FigB_C.ipynb` cell 9).
9. **Bad habits.** Pasted blocks (MOCHA, aifi 36-R, IHA `Dataset/Download_Files.ipynb` cells 6/14/20 same loop three times). Copy drift: sound-life `05` cells 21-28 repeat cells 12-20 and cell 27 loses the `search_id` filter. Hand-typed label vectors `rep('Innate Immune System', times = 10)` and dead references to `tmp1`/`tmp2` (MOCHA `Fig3D_MOCHA_Pathways.R:19-41`). `warnings.filterwarnings("ignore")` and absolute `/home/workspace/` paths (IHA `02_FigB_C` cells 0-1). `print(f"⚠️ ...")` as the failure channel and comments addressed to "your" code (cns `05_basic_qc_filtering_add_metadata.py:47, 57, 87`). `%>%`, `paste0()` paths, no `sessionInfo()` in immgenT; its long `--- internal ---` headers and ~15 `stop()` audits in `Figure4.R` are a 2026 refactor artifact, not the habit.
10. **Exemplars vs weaker.** Exemplars put every parameter in one visible place, name the step in the file name, loop over a named config instead of pasting, and end by recording inputs (`upload_files(input_file_ids=)`) or by writing a record CSV. Weaker repos read as a terminal session saved to disk: no parameters block, hardcoded 1000x copies, undefined objects, results that depend on an earlier unstated cell.

## Persona

This coder maintains a published analysis for years and has been burned by their own past work: two parallel vectors "silently permuted three published panels" (`script/README.md:622`), line-range citations "silently went stale" (`code/R/doc_code.R:4-7`), re-plotting let ggrepel labels and jitter drift, so the site converts the published PDF instead (`render_site_assets.sh:13, 54`), and every cell drop is logged as a counts row rather than trusted to memory (`apply_qc_filters`, sound-life `05` cell 9). They optimise for re-reading in six months and for provenance: a banner names the panel, the `source()` line names the functions, the output name carries step and date, and the run ends by recording its inputs. They trust the package to loop (`dreamlet`, `map2_dfr`) and write code inline until it repeats. They are not an engineer: no CLI, no tests, no config files, no exceptions, and checks only where two artefacts must agree.

## Habits

1. **One named vector or dict drives both the loop and the lookup.** Two parallel vectors once permuted three published panels, so the key and its value never live apart. `gp_letter <- c("GP3" = "3J", "GP29" = "3K", "GP22" = "3L"); for (gp_name in names(gp_letter))` (`Figure3.R:348-349`); `contrast_sets = {'CMV': {'fg': 'Positive', 'bg': 'Negative'}, ...}` then `for contrast in contrasts:` (sound-life DEG nb cells 12-16).
2. **Split by group, map one function, stack once with the key as a column.** The result table then carries its own provenance and the loop body is one call. `names(contrasts) %>% map_df(function(x) topTable(res.dl, coef = x, number=Inf) %>% mutate(coef = x))` (`Kfoury_CancerCell_2021.Rmd:181-187`); `map2_dfr(deseq_res, names(deseq_res), format_deseq_results, group_by = "cohort.cohortGuid", fg = "BR1", bg = "BR2")` (aifi `36-R` cell 20).
3. **Parameters are bare variables at the top; formulas are objects passed in.** A reader sees every knob before any computation and the model is stated once. `max_mito = 10; min_genes = 200; max_genes = 5000` (sound-life `05` cell 4); `form = ~ TB_status + (1|donor) + (1|batch) + ...; res.dl = dreamlet(res.proc, form, ...)` (`Nathan_NatImm_2021.Rmd:153-159`).
4. **Code runs inline until it loops; then one local function that takes data and returns a value or a named list.** Functions exist to serve a loop, not to organise prose, so helpers move to `code/R/<topic>.R` only when a second script needs them and the `source()` line names what is used. `masked_max <- function(auc, positive) { ...; list(value = apply(auc, 2, max, na.rm = TRUE), name = ...) }` (`Figure4.R:154-160`); `source("code/R/lineage_plots.R") # plot_gp_swarm(), plot_loadings_on_mde()` (`Figure3.R:54`); rule stated at `plot_utils.R:1-3`.
5. **One panel is one block: banner, compute a tidy frame, `p_X <-`, `ggsave` with explicit size, source data from the plotted object.** The figure and its numbers come from the same object, so they cannot disagree. `p_1A <- ggplot(plot_df_sub, aes(MDE_1, MDE_2)) + ...; ggsave(filename = paste0(figure_path, "1A.pdf"), plot = p_1A, width = 5, height = 5)` (`Figure1.R:80-88`); `umap_df <- p1[[1]]$data; umap_df %>% fwrite(file.path(wd, "figures_source_data", "Fig1b.csv"))` (IFN `IFN_Fig1.ipynb` cells 13-14).
6. **Align by row names, and check alignment once where a curated file meets computed data.** Joins are for tables; matrices and metadata line up by name, and the one `stopifnot` guards the only place that can silently break. `seurat_meta_filtered <- seurat_meta[rownames(L_pm_filtered), ]` (`Figure3.R:66`); `stopifnot(identical(manual_comments$GP, gp_labels))` (`ExtendedDataTable1_GP_summary.R:81`).
7. **Guard with existence tests, log drops as data rows, never catch exceptions.** A missing file is an expected state; a wrong result should crash loudly. `if os.path.isfile(out_file): continue` (sound-life `10a` cell 27); `counts['n_doublets'] = [sum(adata.obs['predicted_doublet'] == True)]` then `pd.concat(filter_counts).to_csv(...)` (`05` cells 9, 35-36); `tryCatch` only to fall back to a default palette (`plot_utils.R:49-50`).
8. **Hand-off is a file named for step, group and date; the run ends by recording its inputs.** Six months later the file name alone says what made it. `out_csv <- paste0("output/diha_pbmc_", out_group, "_pseudobulk_deseq2_", Sys.Date(), ".csv")` (aifi `36-R` cell 22); `hisepy.upload.upload_files(files = out_list, input_file_ids = in_files, ...)` then `session_info.show()` (`05` cells 44-45).
9. **Comments say why a value is what it is, at the point of use; headings say what the block makes.** The what is in the code; the why is what gets lost. `# A high AUC only means "GP predicts this category" when the category's mean loading is above the overall mean; the other direction is a GP the category lacks.` (`Figure4.R:137-139`); `'MS4A1', # B cells` per marker (aifi `07` cell 13).
10. **Reject: pasted blocks, copied notebooks per subset, blanket warning suppression, absolute home paths, emoji prints as error handling, hand-typed label vectors.** Every one of these produced a drift bug visible in the corpus (sound-life `05` cell 27 lost its filter; MOCHA `Fig3D:19-22` labels cannot be regenerated; `Fig3E:40-99` is eight pasted `mclapply` blocks that should be one `lapply` over a named list).
