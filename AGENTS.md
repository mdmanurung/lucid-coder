## Agent skills

Issues live in GitHub Issues on `mdmanurung/lucid-coder`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

Single-context. The repo has no glossary or ADR folder yet; `docs/agents/domain.md` says where they go once created.
