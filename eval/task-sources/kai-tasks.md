# kai tutorial notebooks as gated eval tasks

Source: kai's retrieval database, Zenodo record 17660667, file `kai_retrieval_251121.zip` (version `251121`, GPL-3.0-or-later as a bundle).
Notebooks are named `org/repo/<path in repo>` from each notebook's `metadata.source_path`; only code cells were searched.
Evidence label: **tut** (seen in the kai tutorial corpus). Tutorial code is evidence of the trap, never a reference style or a default.
Their data is external (GEO, lab buckets, `/lustre` paths), so every fixture below is a small synthetic table shaped like the notebook's input, frozen once under `eval/tasks/<id>/inputs/`.
The licence column is the code licence in `retrieval/licenses/<org>/<repo>/`; it does not cover the data. No candidate needs the notebook's real data.
Excluded as already built: tasks 01-16, 07b and 15b in `eval/tasks/` (catalog 1-10 are issues #9-#18; catalog 1 is #9, 5 is #13, 7 is #15). Where a candidate shares a trap with one, the overlap column says what is new.
Quotes are one line from the notebook.

## Checked and dropped

- `dpeerlab/SEACellsReproducibility/notebooks/CD34-multiome-ATAC-preprocessing.ipynb`: `ad.obs[col] = cell_meta[col].values` looks positional, but `cell_meta` was reindexed with `.loc[ad.obs_names]` first. A usable correct reference for task 1.
- `YosefLab/scvi-hub-reproducibility/fig3_hlca_emphysema.ipynb`: `dc.get_pseudobulk` has no `layer=`, but `X` holds raw counts there (`query_data.X = query_data.raw.X`). It sets `ref_level=['disease', 'normal']`, so the contrast is defined. It does run a per-cell `rank_genes_groups(fibroblast, groupby="disease", ...)` beside the pseudobulk DESeq2 (BSD-3-Clause), a second source for task 12.
- `teichlab/bin2cell/notebooks/N2_demo_analysis_crc_public.ipynb`: `seurat_v3` without `layer=`, but it runs before `normalize_total`, so it reads counts. Correct.
- `scverse/deres/docs/notebooks/example.ipynb` (BSD-3-Clause): unseeded `np.random.randint(0, 10, ...)` assigns fake sample labels on `pbmc3k_processed`, a deliberate toy; no planted answer to gate.
- `Lotfollahi-lab/mintflow-reproducibility`, `YosefLab/popV` and `theislab/CFGen`: `sc.pp.subsample(...)` with no `random_state`, but scanpy defaults to `random_state=0`, so the draw is seeded.
- Inner merges on `.obs` (12 notebooks) and `.dropna()` on metadata (0): no case where the drop changed a result that a gate could check.
