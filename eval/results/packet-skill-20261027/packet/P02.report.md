## Replication unit

The **donor** is the unit of replication. Cells from the same donor share genotype, environment and sample handling, so they are not independent observations of the disease effect; treating cells as replicates (pseudoreplication) badly inflates false positives. All inference is therefore made across 6 donors, leaving 4 residual degrees of freedom.

## Aggregation

Raw UMI counts were **summed** over all cells of each donor, giving a genes x donors count matrix (one pseudobulk sample per donor). Sums, not means, keep the data on the count scale the negative-binomial model expects; differing cell numbers per donor are absorbed by the library-size normalisation. The input is treated as a single cell population: if it mixes cell types, run the skill once per cell type.

## Filters

1. **Cells without metadata** (no row in `cells.tsv`, or missing `donor_id`/`condition`): removed 0 of 1200 cells. 0 `cells.tsv` rows had no matching count column and were ignored.
2. **Donors with fewer than 10 cells**: removed 0 donor(s), 0 cells.
3. **Low-expression genes** (`edgeR::filterByExpr` on pseudobulk counts, grouped by condition, default thresholds `min.count = 10`, `min.total.count = 15`): removed 0 of 50 genes. Removed genes appear in `de.tsv` with `NA` statistics.

No cell-level QC (mitochondrial fraction, doublets, ambient RNA) is done here; it is assumed upstream.

## Normalisation

TMM normalisation factors (`edgeR::normLibSizes`) correct for pseudobulk library size and composition; see the TMM column above.

## Model and why

Negative-binomial generalised linear model with design `~ condition` (healthy as reference), fitted with edgeR's quasi-likelihood pipeline: `estimateDisp`, then `glmQLFit(robust = TRUE)` and a QL F-test. The QL F-test accounts for uncertainty in the dispersion estimates and gives the best type-I error control of the edgeR tests at small sample sizes; robust empirical Bayes shrinks gene-wise dispersions toward a trend, stabilising them with only a handful of donors. Pseudobulk + edgeR/limma is among the best-calibrated approaches for multi-donor single-cell DE in independent benchmarks (Crowell et al. 2020; Squair et al. 2021). Common biological coefficient of variation between donors: 0.106.

## Contrast

Coefficient `groupdisease`: `log2_fc` = log2(disease / healthy) of normalised expression. Positive values mean higher expression in disease.

## Multiple testing

Benjamini-Hochberg FDR over the family of all 50 genes that passed the gene filter (50 of 50 input genes). At q < 0.05, **1 gene(s) significant** (1 up, 0 down in disease).

## Caveats

- With 3 vs 3 donors, power is limited; non-significant genes are not evidence of no effect.
- Each donor belongs to one condition, so any donor-level batch aligned with condition (processing date, site) cannot be separated from disease.
- If cell-type composition differs between conditions, pseudobulk of a mixed population conflates expression change with composition shift.
