# Pseudobulk differential expression: disease vs healthy

Generated by `pseudobulk-de` v1.0.0 on 2026-10-27 with:

```bash
Rscript skills/pseudobulk-de/pseudobulk_de.R --input data --output results/run1
```

## Result

1 of 50 genes differ at q < 0.05: GENE33 (log2 FC +2.02, q = 1.12e-33).

## Data

| Quantity | Input | Used in model |
|---|---|---|
| Donors | 6 (3 healthy, 3 disease) | 6 |
| Cells | 1,200 | 1,200 |
| Genes | 50 | 50 |

Input: `data/counts.tsv` (raw UMI counts, genes x cells) and `data/cells.tsv` (cell -> donor -> condition). Every cell ID matched between the two files and every donor belongs to exactly one condition.

## Replication unit

The **donor** is the unit of replication: 3 healthy vs 3 disease donors. Condition is assigned per donor, so cells from one donor are not independent observations of the condition effect. Testing cells as replicates ignores donor-to-donor variation and yields many false positives; the test here has 4 residual degrees of freedom per gene, not 1,198.

## Aggregation

For each donor and gene, raw UMI counts were **summed over all of that donor's cells** (pseudobulk), giving a 50-gene x 6-donor count matrix. Sums (not means) keep the data as counts, which the negative binomial model requires.

## Filters

Filters were applied in this order. Each row reports what it removed, including zero.

| Step | Unit | Rule | Before | Removed | Kept | Removed IDs |
|---|---|---|---|---|---|---|
| empty cells | cells | total UMI count = 0 | 1200 | 0 | 1200 | none |
| low-cell donors | donors | fewer than 10 cells | 6 | 0 | 6 | none |
| low-expression genes | genes | edgeR::filterByExpr defaults (min.count = 10, min.total.count = 15, by condition) | 50 | 0 | 50 | none |

After filtering, each condition was required to keep at least 2 donors; this held.

## Model

**edgeR quasi-likelihood (QL) negative binomial GLM** (`glmQLFit` + `glmQLFTest`, edgeR 4.8.2), design `~ condition` with `healthy` as reference.

Why this method:

- Pseudobulk counts are overdispersed counts; the negative binomial GLM models them directly.
- With only 3 vs 3 donors, per-gene variance estimates are unstable. The QL F-test shrinks gene-wise dispersions towards a common trend (empirical Bayes) and accounts for the uncertainty in the estimate, which controls the type I error better than likelihood-ratio tests at small sample sizes.
- Pseudobulk + edgeR/limma has been shown to control false discoveries in multi-donor scRNA-seq, where cell-level tests do not (Squair et al. 2021; Crowell et al. 2020).

**Normalization:** TMM (`normLibSizes`) on the pseudobulk library sizes. With a 50-gene panel, one strongly changed, abundant gene shifts every other gene's share of the library, so composition correction matters. TMM assumes most genes are not differentially expressed. Factors ranged 0.978-1.027.

**Dispersion diagnostics:** common biological coefficient of variation (BCV) between donors = 0.106; QL prior degrees of freedom = 8,134.8. A large prior df means the genes' QL dispersions are nearly identical, so each gene's test borrows almost all of its variance information from the other genes. This is why p-values can be very small with only 3 vs 3 donors. Read extreme p-values as "very strong evidence" under the model, not as exact probabilities. For comparison, a distribution-free donor-label permutation test cannot go below p = 1/20 (one-sided).

## Contrast

Coefficient `conditiondisease`: **disease - healthy** on the log2 scale. `log2_fc` > 0 means higher expression in disease. log2 fold changes are edgeR GLM estimates on TMM-normalized counts (default prior count 0.125).

## Multiple testing

Benjamini-Hochberg over the **full family of 50 input genes** (50 tested; any gene removed by the expression filter counts as untested with p = 1, which can only make q-values larger). Significance threshold: q < 0.05.

## Sensitivity check

Re-running the same model with library-size normalization only (no TMM) gives the same set of significant genes at q < 0.05.

## Limitations

- 3 vs 3 donors gives low power for modest effects; a non-significant gene is not evidence of no difference.
- No covariates (sex, age, batch) were available; any donor-level confounder is aliased with condition.
- All cells were pooled per donor; the analysis assumes the cells are one cell type. A shift in cell-type composition between conditions would appear as differential expression.
