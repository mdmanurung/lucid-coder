## R
Tidyverse first: dplyr, tidyr, purrr, readr, stringr, forcats for data frames, never `data.table` or base loops, `apply` or `merge()`; base R only for matrices (`limma`, `colSums()`). Style: `<-`, snake_case, UPPER_SNAKE constants, `TRUE`/`FALSE`, `|>` always, never `%>%`, a new line after every `|>`. Run `air format <file>` after every edit when on PATH (100 columns). `library()` at top, `pkg::fn()` for one-offs. `here::here()`; no `setwd()`. End with `writeLines(capture.output(sessionInfo()), file.path(run_dir, "session_info.txt"))`.
Checks in one line: `stopifnot("meta rows match counts columns" = identical(meta$id, colnames(counts)))`; `relationship = "many-to-one"` on joins. `stop(sprintf(...), call. = FALSE)` only in helpers. No blanket `tryCatch`.
Idioms: `group_split()` or `split()` + `map()`, then `list_rbind(names_to = "cell_type")`; `.by =` for one grouped step; `group_modify()` or `reframe()` for a model per group; `summarise(n_de = sum(fdr < 0.05))`; `across()`, `starts_with()`; `meta[colnames(mat), ]` to align; `set_names()` lookups; `expand_grid()` grids; `str_detect()`, `fct_relevel()`; `case_when(.default = )`; `%in%`, `!str_detect(x, fixed(p))`, never `x[-grep()]`; `[[ ]]`, never partial `$`.
Figures: `theme_set(theme_bw(base_size = 8))` once; `ggsave(plot = p, width = 89, height = 70, units = "mm", device = cairo_pdf)`.
Seeds: `seed =` on `position_jitter()` and `geom_text_repel()`; parallel code sets `RNGkind("L'Ecuyer-CMRG")`.
