## R
Style per R4DS: tidyverse first for data frames, never `data.table`, base loops, `apply` or `merge()`; base R only for matrices. Names lowercase snake_case, constants too; related names share a prefix. `<-`, `TRUE`/`FALSE`. `|>` always, never `%>%`, a new line after every `|>` and every ggplot `+`; one argument per line only when a call overflows. A pipe over ~10 lines splits into named steps. Sections `# Load data ----`. Run `air format <file>` after every edit (100 columns). `here::here()`; no `setwd()`. End with `writeLines(capture.output(sessionInfo()), file.path(run_dir, "session_info.txt"))`.
Checks in one line: `stopifnot("meta rows match counts" = identical(meta$id, colnames(counts)))`; `relationship = "many-to-one"` on joins; `stop(sprintf(...), call. = FALSE)` only in helpers.
Idioms: `split()` + `map(\(x) ...)`, then `list_rbind(names_to = "cell_type")`; `.by =`; `reframe()` for a model per group; `count(x, sort = TRUE)`; `summarise(n_de = sum(fdr < 0.05))`; `join_by()`; `fct(x, levels = )`, never `factor()`; `fct_infreq()`; `if_else()`, `case_when(.default = )`; `separate_wider_delim()`; `str_detect(x, fixed())`; `meta[colnames(mat), ]` to align; `[[ ]]`, never partial `$`.
Figures: `theme_set(theme_bw(base_size = 8))`; `ggsave(plot = p, width = 89, height = 70, units = "mm", device = cairo_pdf)`. `seed =` on jitter and repel; parallel code sets `RNGkind("L'Ecuyer-CMRG")`. Boxes take `outlier.shape = NA` under points; sizes use `scale_size_area()`.
