## R
Style: `<-`, 2 spaces, double quotes, `TRUE`/`FALSE`, snake_case, UPPER_SNAKE constants, `|>` always, never `%>%`, a new line after every `|>` (one step per line, even for two steps), `air` at 100 columns, `library()` at top, `pkg::fn()` for one-offs. Paths with `here::here()`; no `setwd()` or `rm(list = ls())`. `janitor::clean_names()` on import. End with `writeLines(capture.output(sessionInfo()), file.path(run_dir, "session_info.txt"))`.
Errors: `stop()` with `call. = FALSE`; message `<object>: <problem>; <fix>.`, prefixed `fn(): ` inside a helper. Keep it short: `air` does not wrap strings, so a long message breaks the 100-column limit; a call split over lines takes one argument per line. No blanket `tryCatch`.
Figures: `theme_set(theme_bw(base_size = 8))` once; `ggsave(plot = p, width = 89, height = 70, units = "mm", device = cairo_pdf)`, no `dpi` on vectors.
Smells: match with `%in%` or `fixed = TRUE`, filter with `!grepl()`, never `x[-grep()]`. Name `by =` in every join. Dispatch with `switch()` + `match.arg()`; `case_when()` over nested `ifelse()`; `is.numeric(x)`, not `class(x)[[1]]`. `write_tsv()` with rownames moved to a column first. `seed =` on `position_jitter()` and `geom_text_repel()`; parallel code seeds in the worker or sets `RNGkind("L'Ecuyer-CMRG")`.
