## Recurring defaults

- **Figure style.** `sc.settings.set_figure_params(dpi_save=300, facecolor="white", frameon=False, figsize=(8,8))`. Large panels use 14, 18, 30 or 38. FB/figures/fig1.ipynb:33,90; SA/figs/2_Fig2/2a_niches.ipynb:64,408.
- **PDF fonts.** `plt.rcParams['pdf.fonttype']=42` and `['ps.fonttype']=42` so text stays editable. SA/processing_scripts/3_subcluster_coarse.py:14-15.
- **Save pattern.** `plt.savefig("figN/<panel>.pdf", dpi=300, bbox_inches="tight")`, with figure PDFs written to relative `fig*` folders. SA/figs/3_Fig3/3a_bar_plots.ipynb:252; FB/figures/fig5_sfig7_velocity.ipynb:186.
- **Palette.** Annotation colours come from the pickle `color_for_adult_skin2.pkl` (also `colors_new2`). Heatmaps use `Reds` with `set_bad('lightgrey')`. SA/figs/3_Fig3/3g_Epidermal_Myeloid_Heatmap.ipynb:487-488; SA/figs/revision/supp24_GWAS_all_celltyprs.ipynb:1332.
- **Annotation hierarchy.** Keys are `lvl5_annotation` (SA), `lvl0_annotation` (FB scANVI), and `corefb_names2` / `test13` (FB subtypes). The scANVI unlabeled label is the string `"New/unlabelled/excluded"`. SA/processing_scripts/2_acr_map_for_milo.py:302-310; FB/integration/run_scvi_fbs.py:126-127.
- **Seeds.** Leiden `random_state=1`; LARIS `random_seed=27`; RandomForest and StratifiedKFold 42. No global `torch`/`scvi.settings.seed` anywhere (grep found none), so scVI and NicheCompass training are not seeded. SA/figs/sFig1_to_11_dotplots_by_lineage/s1a_b.ipynb:3681; SA/figs/revision/e10f_LARIS_sebimmune.ipynb:715; FB/figures/extended_fig6_classifier.ipynb:208-212.
- **Score-genes constants.** `ctrl_size=1000, n_bins=25`. FB/figures/fig4_by_scarring_risk.ipynb:904-905; SA/figs/revision/supp24_GWAS_all_celltyprs.ipynb:1253-1254.
- **Graph and embedding.** `n_neighbors=20` on `X_scvi`/`X_scarches`, `min_dist=0.1`, UMAP `init_pos="paga"` with `min_dist=0.3`, Leiden res 2 for the atlas and 0.1-0.5 for sub-clusters. SA/processing_scripts/3_subcluster_coarse.py:32-51.
- **scVI/scANVI.** `dispersion="gene"`, `n_latent` 10 (30 in atlas script), `n_layers=1`, early stopping patience 3 (scVI) or 5 (scANVI), GPU for scANVI. SA/processing_scripts/2_acr_map_for_milo.py:302-330,396-399.
- **DE.** t-test in `rank_genes_groups` for markers. Pseudobulk DE uses PyDESeq2 with `min_cells=20, min_counts=1000`. No fixed padj or log2FC cutoff is set in the code I opened. FB/figures/supp_fig1_DEGs.ipynb:129; SA/figs/3_Fig3/mintflow_tdc_degs.ipynb:516-523.
- **Multiple testing.** Benjamini-Hochberg via `multipletests(method="fdr_bh")`. SA/figs/sFig22-27/supp22_clinical_outcome.ipynb:1988.
- **Paths.** Hard-coded `/nfs/team298/ls34/...` and `/lustre/...` for all inputs and outputs. A skill must parameterise these.
