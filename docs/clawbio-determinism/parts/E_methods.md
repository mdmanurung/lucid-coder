## Recurring defaults

- **dreamlet batch options.** `processAssays` uses `min.cells = 5`, `min.counts = 10` and `BPPARAM = SnowParam(6)` or 12 in the main PsychAD analysis. Other datasets lower them to 2 to 3 cells. Cite `repos_new/dreamlet_analysis/PsychAD_r0/PsychAD_r0_analysis.Rmd:272-276` and `repos_new/dreamlet_analysis/COVID_combat/COVID_combat_major.Rmd:143-147`.
- **Significance.** FDR < 0.05 (`adj.P.Val < 0.05`, `p.adjust(..., "fdr")`) is used everywhere. Cite `repos_new/dreamlet_analysis/PsychAD_r0/PsychAD_r0_analysis.Rmd:540-545,616`.
- **Mixed-model formula style.** Random effects `(1|x)` for categorical covariates, `scale(Age)` for continuous ones, and `Dx` fixed for DE but random for VP. Cite `repos_new/dreamlet_analysis/PsychAD_r0/PsychAD_r0_analysis.Rmd:271,478`.
- **Theme.** `theme_classic()` with `theme(aspect.ratio=1)` is the house style. `theme_bw()` is used in the theory simulation and some VP panels. Cite `repos_new/variancePartition_analysis/simulate_vp.Rmd:148-149`; `repos_new/dreamlet_analysis/delta_method/theory_sims.Rmd:126-127`.
- **Palettes.** Variance fractions use `brewer.pal(.., "Set1")` plus `grey85` (and `grey65` for count noise). Diverging heatmaps use `scale_fill_gradient2(low="blue", mid="white", high="red")`. Volcano is `c("grey","darkred")`. Cell-type labels use `variancePartition::ggColorHue(n)`. Cite `repos_new/dreamlet_analysis/PsychAD_r0/PsychAD_r0_analysis.Rmd:294-295`; `repos_new/dreamlet_analysis/COVID_combat/COVID_combat_major.Rmd:246`; `repos_new/dreamlet_analysis/PsychAD_r0/PsychAD_r0_compare_methods.Rmd:366`.
- **Cell-type order.** A fixed `ctorder` vector of 22 PsychAD subclasses controls facet order via `assays=ctorder`. Cite `repos_new/dreamlet_analysis/PsychAD_r0/PsychAD_r0_analysis.Rmd:65-67`.
- **Facet grids.** `ncol=4` for dreamlet plots (5 for Mathys 2023). Cite `repos_new/dreamlet_analysis/Mathys_2023/Mathys_2023_Cell_Type.Rmd:153`.
- **Gene sets.** GO from `get_GeneOntology(to="SYMBOL")`, drop sets over 1000 genes; MSigDB via `get_MSigDB`. Cite `repos_new/dreamlet_analysis/PsychAD_r0/PsychAD_r0_analysis.Rmd:743-750`.
- **Seeds.** Seeds appear only in simulations: `set.seed(1)` in `simulate_vp.Rmd` and `downsampling_results.Rmd`, `set.seed(42)` in `toy_example.Rmd`. The dreamlet scripts set none (the `sample()` in `subsample_cells.R` is unseeded). Cite `repos_new/variancePartition_analysis/simulate_vp.Rmd:47`; `repos_new/GTestimate-Paper/notebooks/downsampling_results.Rmd:19`; `repos_new/GTestimate-Paper/notebooks/toy_example.Rmd:23`; `repos_new/dreamlet_analysis/PsychAD_r0/subsample_cells.R:55`.
- **Output paths and sizes.** Dreamlet figures are saved to hard-coded `~/www/test.pdf` (not reproducible); VP supplements use `Figure_S_<dataset>_N.pdf` at 12 wide x 22 to 30 high with `plot_grid(ncol=4)`; GTestimate uses `ggsave(str_glue('{folder}name.pdf'), plot, width=6.6, height=4)` for reports and mm sizes (60/86/120/178) for publication. Cite `repos_new/dreamlet_analysis/COVID_combat/COVID_combat_major.Rmd:250`; `repos_new/variancePartition_analysis/Nathan_NatImm_2021.Rmd:264-267`; `repos_new/GTestimate-Paper/notebooks/cta_seq_results.Rmd:96`; `repos_new/GTestimate-Paper/notebooks/pub_figures.Rmd:63`.
- **Knitr.** `dev=c("png","pdf")`, `cache=TRUE`. Cite `repos_new/dreamlet_analysis/delta_method/theory_sims.Rmd:36-43`.
- **Seurat defaults (GTestimate).** `FindVariableFeatures(nfeatures=2000)`, 30 PCs for ARI benchmark, 10 PCs for pbmc3k at resolution 0.5, `FindClusters(resolution=1)` default. Cite `repos_new/GTestimate-Paper/notebooks/clustering_experimentally_annotated_cells.Rmd:57-61`; `repos_new/GTestimate-Paper/notebooks/downstream_analysis_results.Rmd:49-55`.
- **Hard-coded cluster paths.** Data paths point to `/sc/arion/projects/...` (Mount Sinai Minerva), so a skill must parametrize input files. Cite `repos_new/dreamlet_analysis/PsychAD_r0/subsample_cells.R:34-36`.
- **No ROC/FDR-calibration or runtime plots exist.** Benchmarks here are accuracy vs truth (rMSE, estimation error, ARI, Jaccard) and agreement scatters. No QQ plot, ROC, power curve or runtime bar was found by grep of `ROC`, `power`, `system.time`, `plotQQ`.
